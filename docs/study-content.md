# Учебные материалы v1

Выбор пользователя: Java, английский A2 → B2, Java backend-разработчик. 12 занятий Java, 24 английского (8 на этап) и 12 backend в новой версии v2. Старые планы v1 содержат 8 backend-занятий и продолжают работать со своими материалами. Это конечный маршрут практики, не гарантия достижения CEFR или профессиональной квалификации. Свободные решения, речь и письмо оцениваются по явным критериям самим учащимся; автоматическая часть проверяет только заданные вопросы.

Все объяснения, истории, примеры и упражнения созданы для платформы. Внешние ссылки — дополнительные первичные справочники, они не заменяют материал урока. Перечень источников находится в `backend/app/content/study-v1.json`.

Аудио: оригинальные английские сценарии из поля transcript, локальный синтез macOS Samantha (135/150/165 слов в минуту для A2/B1/B2), PCM WAV. Это явно обозначенные синтетические учебные записи, не живые носители и не проверка понимания разных акцентов. Файлы находятся в frontend/public/audio/study-v1 и не требуют внешнего TTS при просмотре. Расшифровка доступна после самостоятельного прослушивания. Звук включается пользователем.

Java: обычный синтаксис Java 21, без preview-функций. 12 полных примеров компилируются отдельно как Main.java. Код пользователя не выполняется сервером. Backend содержит полные примеры и явно отмеченные фрагменты; JDBC требует локальной учебной PostgreSQL и драйвера. Публичная авторизация учебного сервиса и его развёртывание не объявляются готовыми.

Версии неизменяемы: расширение backend-маршрута сохранено отдельно в `backend/app/content/study-backend-v2.json`; исходный v1 не меняется. Изменение смысла урока требует новой версии набора. Сохранённые попытки хранят снимок задания, ответов, критериев и результата, поэтому обновление материалов не переписывает историю.

## Актуальные расширения

Для новых планов каталог предлагает Java v2 (14 занятий), Go v2 (32), английский v2 (27; по 9 на A2/B1/B2) и Java backend v3 (14). Добавления сохранены в `backend/app/content/study-extensions-v1.json`; исторические v1 и backend v2 не изменены. Новые английские записи лежат в `frontend/public/audio/study-v2` и имеют тот же формат PCM WAV. Таблица добавленных глав и границы проверки — в `docs/verification/2026-10-12-study-depth.md`.

Подбор чтения в анкете теперь показывается только для вариантов «Чтение», «Java и чтение» и «Go и чтение». При выборе одного языка программирования или пропуске обучения случайная книга не предлагается. Экран «Обучение» берёт количество занятий из текущего каталога или из активного исторического плана.
