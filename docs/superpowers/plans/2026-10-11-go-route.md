# Go Route Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give users a complete original Go course inside Education, with personal plans and progress.

**Architecture:** Keep the existing study engine. Add a separate immutable `go` v1 content file; connect it to catalog, onboarding, Education, Sections, Today, and the existing Study page. Preserve Java curricula and archived plans.

**Tech Stack:** Python/FastAPI, JSON authored content, React/TypeScript, pytest, Vitest, Go toolchain for example validation.

**Spec:** `docs/superpowers/go-learning-route-design.md`

## Global Constraints

- Course contains 30 original lessons in six chapters; each lesson has explanation, runnable example, practice, solution, self-check, and quiz.
- Telegram posts are topic references only; do not copy author text or media.
- Keep `study-v1.json` and `study-backend-v2.json` unchanged.
- Keep Java, Java backend, and existing user history accessible.

## Review Focus

- Old saved onboarding answers still parse.
- Selecting Go replaces only the chosen education route after existing confirmation.
- A Go plan can create, save a draft, submit a result, and resume.
- Examples run under the installed Go toolchain without external dependencies.
- Missing Telegram post access never leaves an empty lesson.
