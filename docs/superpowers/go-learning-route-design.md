# Go как второй маршрут программирования — дизайн для согласования

Статус: направление и полный курс подтверждены пользователем; реализация выполняется по этапам.

## Цель и границы

Добавить Go в сферу «Обучение» как самостоятельный маршрут с готовыми материалами и личным планом. Java остаётся доступной. Маршрут «Профессия» продолжает означать Java backend; включение Go не переименовывает его в Go backend и не изменяет сохранённые планы.

Публикация и платные сервисы не входят в этот этап. Код пользователя не выполняется на сервере. Автоматическая проверка касается только однозначных вопросов; практический код пользователь проверяет по критериям сам.

## Содержание

Создать собственный локальный курс `go`, версия `v1`, в отдельном файле контента. Это должен быть самостоятельный курс внутри платформы, а не каталог ссылок или только 12 вводных занятий. Предлагаемый объём — 30 последовательных занятий в шести главах:

1. **Старт (1–5):** установка и первый модуль; переменные и типы; условия и циклы; функции и область видимости; строки и Unicode.
2. **Структуры данных (6–10):** массивы и срезы; карты; структуры; методы и указатели; интерфейсы.
3. **Надёжный код (11–15):** ошибки; `defer` и работа с ресурсами; пакеты и модули; ввод/вывод и файлы; тесты и табличные тесты.
4. **Прикладной Go (16–20):** JSON; HTTP клиент; HTTP сервер и маршруты стандартной библиотеки; конфигурация и окружение; контекст и отмена.
5. **Параллельность и хранение (21–25):** горутины; каналы; `select` и таймауты; `sync` и гонки данных; `database/sql` и миграции как учебный обзор.
6. **Проект (26–30):** модель и API небольшого сервиса; хранение и обработка ошибок; тесты обработчиков; запуск и проверка; итоговое задание и чек-лист самостоятельного расширения.

Каждое занятие содержит объяснение, запускаемый пример, практику, вопросы для самопроверки, разбор решения и источники. Главы заканчиваются проверяемым мини-результатом; последняя глава собирает их в проект. Примеры проверяются локальным `go test`/`go run`, если Go установлен. Курс охватывает путь с нуля до самостоятельного учебного проекта; он не обещает исчерпать всю экосистему Go, экспертную оценку кода или трудоустройство.

Темы канала Нияза можно использовать как подсказки для выбора и последовательности тем. Тексты, PDF и изображения автора не копируются в проект без разрешения. Основная техническая база — официальные [Go Tutorials](https://go.dev/doc/tutorial/) и [A Tour of Go](https://go.dev/tour/list); внешние ссылки дополняют собственные материалы внутри платформы.

## Подключение к платформе

- `backend/app/study.py` находит отдельный курс Go по идентификатору `go` и версии `v1`; старые `study-v1` и `study-backend-v2` остаются неизменными. Снимки уроков в попытках и архивных планах сохраняются.
- В «Обучении» появляются две отдельные точки входа: Java и Go. На странице Go используются существующие план, урок, черновик, результат, история и календарь. Страница «Сегодня» показывает следующий урок активного плана Go тем же способом, что и другие учебные планы.
- В анкете выбор программирования расширяется Go. Старые ответы (`java`, `reading`, `both`, `none`) продолжают читаться. Предлагаемые новые варианты: `go` и `go-reading`; `both` по-прежнему означает Java и чтение. Это сохраняет совместимость уже сохранённых анкет. При смене выбора активный прежний план архивируется только после существующего подтверждения; история остаётся.
- В списке сфер «Обучение» показывает текущий шаг активного Go, если выбран Go; Java и чтение остаются доступными через страницу сферы. Список общих задач остаётся отдельным.

## Проверка результата

Проверить все 30 полноценных занятий, валидность примеров Go и ссылок, выбор Go в анкете, предпросмотр до запуска, создание и замену плана с сохранением истории, следующий урок на «Сегодня», сохранение черновика и результата, мобильную страницу. Проверка не должна изменять действующие планы Java или редактировать опубликованные материалы `study-v1`.

## Требующее подтверждения решение

Предлагаются 30 занятий Go от основ до учебного сервиса и две новые опции анкеты: Go и Go вместе с чтением. Одновременный запуск Java и Go через анкету пока не предлагается; оба маршрута доступны отдельно из «Обучения».
