# Система оформления

Согласована 14 октября 2026 года. Режим интерфейса — рабочее приложение: ясная иерархия, читаемые формы и одинаковые действия на всех экранах.

- Шрифт: локальный Noto Sans (`frontend/public/fonts/NotoSans-Variable.ttf`), `font-display: optional`, системный запасной шрифт. Лицензия в `frontend/public/fonts/OFL.txt`. Проверено наличие русской кириллицы и казахских Ә Ғ Қ Ң Ө Ұ Ү Һ І в файле шрифта.
- Цвета: фон `#f4f3f0`, поверхность `#fff`, основной текст `#242424`, вторичный `#625f59`, линия `#dcd9d2`, основное действие `#242424`. Семантические токены находятся в `frontend/src/design-system.css`.
- Типографика: 16 px основной текст, 14 px подписи, 13 px пояснения, 36–48 px заголовок страницы. Межстрочный интервал основного текста 1.5.
- Отступы: 4, 8, 12, 16, 24, 32 px; скругления: 12 px для управления, 18 px для карточек, 20 px для диалогов.
- Общие React-компоненты: `Button`, `Input`, `Select`, `Dialog`, `Card` в `frontend/src/components/ui.tsx`. У кнопок варианты `primary`, `secondary`, `quiet`, `danger`. Загрузка сохраняет подпись и размеры действия.
- Новые экраны используют эти компоненты и токены. Существующие классы `primaryButton`, `secondaryButton`, `card` получают ту же основу из общего CSS, пока старые страницы переводятся на компоненты.
- Компоновка использует Grid/Flex и `gap`; высота карточек с текстом определяется содержимым. Для длинных надписей разрешён перенос. Фокус должен оставаться видимым с клавиатуры.
