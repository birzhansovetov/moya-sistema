# Охват ступенчатых подсказок для учебных маршрутов

Дата: 14 октября 2026 года. Проверка: `python -m app.coverage --check`.

Стартовый отчёт показал 397 сочетаний версия курса / урок / вопрос без готовой подсказки. Добавлены оригинальные подсказки, следующий шаг и разбор для первых двух уроков Java, Go, английского A2 и Java backend во всех существующих версиях этих уроков. Это 40 записей для исторических и текущих версий. Сейчас непокрыты 357 сочетаний; недостижимых записей помощи нет.

Первая партия выбрана по явным пробелам: запуск и базовые операции Java и Go, первые грамматические и аудио задания английского, а также воспроизводимый проект и HTTP в backend-маршруте. Она не означает, что все четыре курса уже снабжены подсказками. Следующие партии следует выбирать по редакционному отчёту использования и отрицательных оценок, а не по одному числу записей.

Каждая подсказка проверяется против принятых ответов соответствующего вопроса, имеет отдельную версию курса и дату повторной проверки. Исторические попытки и файлы курсов не менялись.
