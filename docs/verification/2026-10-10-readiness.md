# Проверка готовности личной платформы — 10 октября 2026

## Проверено локально

- Все шесть сфер открыты на ширине 390 и 1280 px: проверены разделы спорта, питания, чтения, Java, профессии, английского, финансов и личного дневника. На проверенных экранах нет горизонтального переполнения, пропавших основных заголовков или ошибок загрузки.
- Каталог здоровья расширен до шести программ: для дома, улицы и зала есть полные и 25-минутные варианты. Анкета выбирает программу по времени и оборудованию. Исторические снимки уже сохранённых планов не меняются.
- Библиотека питания содержит 14 рецептов. Появились два обеда до 30 минут и два завтрака без глютеновых ингредиентов; один из них также не содержит молоко и яйца. Совместимость всё равно зависит от выбранных исключений и условий приготовления.
- В профиле доступны зашифрованная выгрузка, предпросмотр архива и восстановление после скачивания текущей копии. API-тесты покрывают две учётные записи, смену пароля, испорченный файл, повторное использование разрешения и откат при ошибке базы. Экран проверен на 390 и 1280 px без горизонтального переполнения; полный цикл через браузер с реальным личным паролем не выполнялся.
- Backend: `79 passed` при полном `.venv/bin/python -m pytest -q` (4 предупреждения зависимостей). Frontend: `65 passed` при `npm test -- --run`; `npm run build` проходит. Это локальные проверки, без Neon, Gmail и публичного адреса. Проверка кода после реализации выявила гонку параллельных записей; общий блокировщик по аккаунту добавлен ко всем маршрутам изменения данных, включая создание финансовых категорий. Размер запроса с архивом ограничен до разбора multipart. Конкурентная проверка на PostgreSQL остаётся частью проверки опубликованного сервиса.

## До публикации

1. Проверить архив на опубликованном сервисе с отдельными тестовыми учётными записями и базой Neon после подключения сервисов. Локальная реализация готова; публичная проверка ещё не проводилась.
2. Проверить выбранный Gmail API на реальном личном аккаунте. Google сообщает, что в режиме OAuth External / Testing offline refresh token для чувствительных scopes истекает через 7 дней. Для устойчивой отправки писем нужно проверить допустимый для этого личного приложения режим OAuth: <https://support.google.com/cloud/answer/15549945?hl=en>. Не вводить ключи в репозиторий или чат.
3. Подключить Git remote и аккаунты Cloudflare, Render, Neon и Google. На момент проверки `git remote -v` пуст. Публичный сервис не создан и не проверен.
4. После настройки проверить миграции на Neon, прокси Pages → Render, письма, вход, сохранение и восстановление архива, данные после перезапуска сервиса и изоляцию двух аккаунтов.

## Ограничения бесплатного размещения

Render Free останавливает веб-сервис после 15 минут без запросов, а его локальная файловая система временная; постоянные данные должны оставаться в Neon: <https://render.com/docs/free>. Cloudflare Pages Free допускает 500 сборок в месяц; запросы к Pages Functions расходуют квоту Workers: <https://developers.cloudflare.com/pages/platform/limits/>. Перед подключением платёжного метода проверить лимиты и предупреждения о возможных списаниях.
