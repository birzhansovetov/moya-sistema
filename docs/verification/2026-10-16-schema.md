# Schema-разметка «Моей системы»

Дата: 16 октября 2026. Основной сайт: https://moya-sistema.pages.dev/.

## Изменение

В `frontend/index.html` добавлен один серверно доступный JSON-LD-блок с графом `WebSite` и `WebApplication`, связанными стабильными абсолютными `@id`. Имя «Моя система», русский язык интерфейса, категория LifestyleApplication, работа через браузер и JavaScript. Это общее описание продукта, а не разметка личных записей или отдельных страниц.

Рейтинги, отзывы, цена, организация и поисковое действие не добавлены: подтверждённых публичных данных для них нет. UI, личные планы, авторизация и API не изменены.

## Проверки

- Новый тест сначала обнаружил отсутствие JSON-LD, после реализации прошёл.
- Все 159 frontend-тестов прошли; TypeScript/Vite production build прошёл. Существующее предупреждение о размере JS >500KB осталось.
- Schema.org Validator распознал WebSite со связанным WebApplication: нет ошибок и предупреждений.
- После публикации HTML `/` и `/login` на основном домене содержит ровно один JSON-LD-блок; разобранные данные в точности совпали с `dist/index.html`.
- Cloudflare Pages деплой: https://04c5fea1.moya-sistema.pages.dev/; опубликован в существующий проект moya-sistema, ветка main.

Google Rich Results Test не используется как доказательство eligibility: для расширенного результата SoftwareApplication Google требует реальные offer и review/aggregateRating. Эти данные не выдумывались. Валидность Schema.org не гарантирует расширенный сниппет, индексацию или позицию.

Источники требований: https://schema.org/WebApplication и https://developers.google.com/search/docs/appearance/structured-data/software-app.

Внешняя повторная проверка опубликованного URL завершена: Schema.org показал «НЕТ ОШИБОК» и «НЕТ ПРЕДУПРЕЖДЕНИЙ». Валидатор перешёл на публичный экран `/login`; JSON-LD доступен до авторизации. Снимок: `assets/schema/published-validation.png`.
