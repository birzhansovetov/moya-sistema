# Локальные улучшения для личного использования — 10 октября 2026

## Объём

- «Мой день»: переключение даты и прямые ссылки к планам и задачам.
- Учебные разделы: компактный выбор урока на телефоне и переход к занятию.
- Незавершённые занятия: явное сохранение черновика через FastAPI, восстановление после повторного посещения, удаление после подтверждённой попытки.
- Java и Java Backend: 20 предметных вопросов вместо повторяющихся общих; все 44 урока содержат упражнение для повторения после ошибочного ответа.

## Проверено

- Backend: `65 passed` в полном `pytest`.
- Frontend: `62 passed` в полном `vitest`; TypeScript и Vite build прошли.
- JSON курсов синтаксически валиден; тест содержания проверяет темы вопросов и упражнения для повторения.
- В локальном браузере: выбор урока и переход к статье, сохранение черновика и восстановление после перезагрузки, удаление черновика после подтверждённой попытки. На уроке Java неверный ответ показал объяснение и дополнительную практику.
- После независимого ревью проверены конфликты двух устройств: устаревшая попытка получает `409` и сохраняет новый черновик; после подтверждённой попытки можно сохранить новую практику. Более новая серверная версия заменяет нетронутый локальный текст; несохранённые изменения сохраняются на экране. Переход «К занятию» из истории открывает урок.
- Макеты на 390 и 1280 px проверены без горизонтального переполнения в учебном разделе; навигация по дате проверена в «Мой день».

## Границы проверки

Платформа остаётся локальной. Публикация, доставка писем, Neon и работа облачных хостингов не проверялись. Практику по свободному тексту, Java-код и устную речь пользователь оценивает по рубрике самостоятельно; автоматические баллы относятся к вопросам с вариантами ответа. Сохранение черновика требует нажатия кнопки.
