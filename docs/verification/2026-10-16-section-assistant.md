## Ограничения и решения

- Бесплатный облачный режим объясняет публичную справку/каталог; нет свободного чата, анализа дневника/финансов/тела/личной книги или автономной замены плана.
- Текущая проверка источников упражнений, гайдов и карточек книг соответствует существующему каталогу плюс отзывы. У этих типов пока нет полного набора индивидуальных сроков повторной редакторской проверки; рецепты дополнительно проверяются reviewed_variant.
- Кнопка материала может разрешать текущую версию через список сервера; явно устаревшая версия отвергается. Это требует дополнительной загрузки списка.
- Использован существующий отдельный release checkout, основной рабочий каталог с посторонними изменениями сохранён; целевые файлы синхронизированы после проверки отсутствия конфликтов.
- Квоты, валидация и готовые подсказки обеспечивают запасной режим; смысловая точность каждого ответа модели не гарантируется.

## Откат

Очистить CLOUD_AI_SECTIONS — общая помощь останется authored. CLOUD_AI_ENABLED=false отключает также облачную учебную помощь. При регрессии интерфейса переопубликовать предыдущий frontend/backend; добавочную таблицу при откате приложения не удалять.
