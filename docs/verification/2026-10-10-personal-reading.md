# Личное, книги и гайды — проверка 10 октября 2026

## Объём

Продолжены согласованные архитектура и существующий план, задачи 13–15. Реализованы личный дневник, события, эксперименты/хобби, карточки книг, изменяемый темп чтения, история страниц и заметок; всё с собственным FastAPI и пользовательской изоляцией. Семь авторских гайдов: три личных, два по чтению, два по учёту расходов. Три стартовые литературные рекомендации с вопросами; названия/авторы и ссылки сверены с поисковой выдачей Культура.РФ. Прямое открытие двух страниц через веб-инструмент вернуло техническую ошибку; чтение полного текста на внешнем сайте в этой проверке не подтверждено. Тексты произведений не скопированы.

Дневник не публикуется и не попадает в календарь: только ID, название, дата, тип и выполненность события/эксперимента. Эти записи не создают задачи. «Мой день» показывает текущий шаг чтения и дату будущей записи, без заявления, что это исторический снимок закладки.

## Ограничения и решения

- Новые учебные маршруты программирования, профессии и человеческих языков ожидают ответа на запрос выбора, отправленный в этом ходе. Их контент не выбран за пользователя. В «Обучении» готова часть «Книги»; остальные части обозначены честно.
- Продолжена существующая ветка/план; новые этапы интегрируются вместе с предыдущими. Новые провайдеры, ИИ и платные сервисы не подключались.
- Полные тексты книг открываются по внешним библиотечным ссылкам; внутри платформы — авторские гайды, вопросы и личные журналы. Количество страниц относится к собственному изданию, не выдумывается.
- Прогресс меняется при сохранении реальных записей; чувства и ответы не генерируются.
- Neon/PostgreSQL, внешняя Gmail-почта и публикация в этом ходе не проверялись. Локальная SQLite-проверка не заменяет проверку перед публикацией.

## Финальное ревью

Отдельный read-only рецензент проверил расширение после Finance. Найден один Important/P2: поздний ответ сохранения мог закрыть другой редактор и потерять его черновик. Critical и Minor не найдено.

Добавлены три регрессионных теста: завершение создания личной записи при редактировании другой; Escape во время отправки книги с последующей ошибкой; завершение новой заметки чтения при редактировании старой. До исправления все три падали из-за исчезнувшего диалога. После исправления 7/7 тестов дневника и чтения прошли. Диалоги блокируют закрытие во время отправки, обработчики встроенных форм не закрывают редакторы, завершение редактора связано с его исходным экземпляром. При ошибке поля сохраняются. Повторное ревью не запускалось: один проход исправлений по executing-plans.

Финальная полная проверка: `.venv/bin/python -m pytest -q` — 51 passed / 4 прежних предупреждения; `npm test` — 44 passed / 17 файлов; `npm run build` — успешно; `git diff --check` — чисто. Прямой запуск `.venv/bin/pytest` сначала не нашёл локальный модуль `app`; запуск через тот же Python с `-m pytest` корректно использует каталог проекта.

### Решения по границам ревью

1. Продолжены текущие архитектура, план и ветка по просьбе пользователя; цена решения — этапы остаются связанными в одной ветке.
2. Выбор программирования, профессии и человеческого языка оставлен пользователю, как требует архитектура; цена — эти направления пока не наполнены. Замечание рецензента об этой границе принято без расширения объёма.
3. Проверки Neon/PostgreSQL, конкуренции запросов в production и публикации оставлены на этап подключения окружения; цена — локальные тесты не доказывают production-работоспособность.
4. Доступность полных внешних текстов не подтверждена; внутри готовы собственные вопросы и гайды, страницы вводятся для издания пользователя. Цена — внешний источник может быть недоступен.
5. Черновики сохраняются при ошибках и обновлении данных, но не после намеренного ухода со страницы; постоянное хранение несохранённых черновиков не добавлено. Цена — при уходе несохранённый текст теряется.

Отложенных Minor нет. Изменения сохранены локально, публикация не выполнялась.
