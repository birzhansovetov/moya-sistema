# Облачные объяснения без личных данных — 15 октября 2026

Выбор пользователя: бесплатный Gemini API, только объяснения материалов, без личных данных. Это изменение существующей помощи к урокам; персональный подбор анкеты и прогресс остаются детерминированными на сервере. Локальный Ollama сохраняется для разработки.

## Контракт

- Render вызывает Gemini напрямую. Ключ хранится только в `GEMINI_API_KEY`, не попадает в frontend, URL запроса, логи или repr настроек.
- В Gemini передаются только опубликованный авторский фрагмент, тип объяснения и язык. Нет user ID, plan ID, ответов, прогресса, кода ошибки, дневника, финансов, аллергий или других ответов анкеты.
- Личный разбор попытки `review` не использует облако. Согласие на локальную передачу ответа показывается только там, где действительно включён локальный обработчик.
- 20 обращений в час на аккаунт; один активный запрос на процесс, не более трёх некэшированных вызовов в минуту, таймаут 12 секунд. При сбое минутная пауза. Кэш до 256 общих фрагментов на 24 часа включает хеш текста, версию промпта и модель.
- Неверный JSON, пустой/слишком длинный текст, ссылки, раскрытие точного ответа в намёке и следующем шаге заменяются готовым фрагментом. Проверка совпадения ответа не гарантирует семантическое отсутствие спойлеров; качество оценивается отдельно.
- Результат явно подписан `Объяснение ИИ · Gemini`; запасной режим — `Готовое объяснение из урока`.

## Настройка

В проекте Google без подключённой оплаты создать ключ и сохранить его в Render. Настройки сервера:

```
CLOUD_AI_ENABLED=true
GEMINI_API_KEY=<только в Render>
GEMINI_MODEL=gemini-3.5-flash-lite
```

Бесплатные квоты зависят от проекта Google и не гарантируют неограниченную работу. Оплата не включается приложением. При исчерпании квоты урок остаётся доступен с готовыми подсказками.

## Проверка

Тесты проверяют production-ветку через подменённый транспорт, отсутствие личного текста в upstream payload, кэш, отказ при отсутствии ключа, запрет облачного разбора попыток, ошибочный ответ и таймаут, границы нагрузки, передачу ключа только в заголовке. UI-тест проверяет подпись облачного ответа и отсутствие передачи личного решения.

Проверки после исправления найденной ревью ошибки обработки JSON: 298 backend-тестов и 150 frontend-тестов прошли, TypeScript/Vite сборка успешна. Ключ и флаг включения сохранены в Render; значение ключа не копируется в репозиторий. Настоящий ответ провайдера и публикация проверяются отдельно.
