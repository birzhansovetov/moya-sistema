# Локальные EPUB

Двенадцать EPUB в этом каталоге получены 11.10.2026 через [экспорт Викитеки](https://ws-export.wmcloud.org/) со страниц, указанных в `../book_suggestions.json` (`ebook_source`). Это оригинальные русские произведения Антона Чехова (ум. 1904), Льва Толстого (ум. 1910), Александра Грина (ум. 1932), Ивана Тургенева (ум. 1883), Александра Пушкина (ум. 1837) и Максима Горького (ум. 1936). Срок охраны оригинальных текстов по правилу жизнь автора плюс 70 лет истёк. Каждый EPUB сохраняет страницу источника и атрибуцию Викитеки. Современные издания, переводы и иллюстрации требуют отдельной проверки прав перед добавлением.
